# 旋回振動問題の解決計画

## 問題の概要

90度旋回時、角度制御がきれいに収束せず、目標値付近で振動する。

## 現状の分析

### 旋回制御の実装（place_controller.cpp）

- 台形速度プロファイル（加速→巡航→減速）で目標角度を生成
- 追従制御：`FF(目標角速度) + PID(角度誤差) + D(角速度誤差)`
- 制御周期：10ms窓で速度推定・PID更新、毎msでFFと加速度FF更新

### 現在のパラメータ（params.cpp）

| パラメータ | 値 | 単位 | 説明 |
|-----------|-----|------|------|
| pivot_max_radps | 7.8 | rad/s | 巡航角速度 |
| pivot_accel | 20.0 | rad/s² | 角加速度 |
| pivot_kf | 19.0 | - | FFゲイン |
| pivot_kp | 400.0 | - | 角度Pゲイン |
| pivot_ki | 40.0 | - | 角度Iゲイン |
| pivot_kd | 50.0 | - | 角速度Dゲイン |
| pivot_out_max | 500.0 | - | 旋回側duty上限 |

### 90度旋回の理論値

- 最大角速度到達時間: 7.8/20 = 0.39秒
- 減速開始角度: ω²/(2α) = 7.8²/(2×20) = 1.52 rad ≈ 87度
- 90度(1.57rad)旋回ではほぼ最大角速度まで到達してから減速開始

### 振動の原因として考えられるもの

1. **Pゲイン(400)が高すぎる可能性** - 目標付近で過敏に反応
2. **Iゲイン(40)の積分項** - 目標付近でも積分が残り、振動を助長
3. **Dゲイン(50)の角速度誤差項** - ジャイロノイズに敏感
4. **減速プロファイル** - 減速率に対して慣性が大きくオーバーシュート

**分析結果:**
- 最終角度誤差: -0.62度
- 最大誤差: 5.26度（オーバーシュート時）
- 目標値交叉回数: 2回
- 定常状態での平均誤差: -1.46度

**観察される問題:**
1. 目標角度（90度=1.571rad）を約10度行き過ぎる（1.759rad=100.8度）
2. 減速開始後の角度の振動が大きい（1.516〜1.759radの範囲）
3. dutyの符号が頻繁に切り替わっている（制御が安定していない）

### Phase 2: 根本原因の特定

**ファームウェア更新完了**（2026-11-12）

**重大な問題発見:**
- `TURN`コマンドは**DONEを返さない**（継続制御）
- `JOGTURN`コマンドは**DONEを返す**（到達・整定で完了通知）
- `mobile_base.turn()`は`TURN`コマンドで`DONE`を待っているため、タイムアウトしていた
- これがPhase2で「無茶苦茶な動き」をした原因

**テストスクリプト修正済み:**
- 各テスト前に角度リセット（RANG）を追加
- パラメータ設定の応答処理を修正

**次のステップ:**
`TURN`コマンドを使う場合はDONEを待たない方法に変更する必要あり。

**テスト項目:**
- [x] ベースライン（現状）確認（Phase1の方法で実施済み）
