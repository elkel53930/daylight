# Shared venv for ui/, default_app/, and camera/ (all touch the same
# Raspberry Pi hardware libraries, so splitting them into separate venvs
# buys no real isolation). Create with --system-site-packages so
# apt-installed hardware bindings (notably picamera2, which is not
# reliably pip-installable) resolve from the system Python:
#
#   sudo apt install -y python3-picamera2
#   python3 -m venv --system-site-packages software/venv
#   software/venv/bin/pip install -r software/requirements.txt
#
# picamera2 itself is deliberately NOT listed below — it must come from
# the apt package above, not pip.
#
# beacon/ has no hardware dependency and keeps its own fully-isolated venv
# (see beacon/setup.sh).
lgpio
Pillow
luma.core
luma.oled
msgpack
PyYAML
requests
